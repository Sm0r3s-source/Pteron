# Pteron

A low-memory general-purpose browser built on the [Servo](https://servo.org) engine (v0.7.0).

This repository holds Pteron's own changes as files laid out like the Servo source tree.
To build: check out Servo v0.7.0, copy these folders over it, and run `./mach build -r`.

Releases (Windows) are on the Releases page. Pteron can update itself from Settings > About.
